# WLI Craft — حالة سيرفر ماينكرافت في إيمبد ديسكورد

يحدّث نفس الرسالة التي أرسلتها من Embed Generator في وضع Webhook. لا تحتاج تشغّل جهازك؛ GitHub Actions ينفّذ الفحص تلقائيًا تقريبًا كل 5 دقائق (قد تتأخر المهام المجدولة).

## 1. أنشئ رسالة من Embed Generator

1. في ديسكورد افتح إعدادات روم المعلومات ← **Integrations** ← **Webhooks** ← **New Webhook**.
2. سمّه `WLI Craft` وارفع صورة السيرفر، وانسخ **Webhook URL**. رابط سري: لا ترسله لأي شخص ولا تكتبه في المستودع.
3. افتح https://message.style/app واختر **Webhook** بدل **Channel**.
4. الصق الرابط، وأنشئ **Embed عادي** بعنوان `⛏️ WLI Craft | Server Status`. أضف 3 حقول مبدئية (الحالة، اللاعبون، الآيبي). لا تستخدم Components V2 هنا.
5. اضغط **Send Message** مرة واحدة. نفس الرسالة ستتحدث لاحقًا. لا تضغط إرسال مرة ثانية.
6. من ديسكورد فعّل **User Settings → Advanced → Developer Mode**.
7. اضغط بزر الفأرة اليمين على الرسالة التي أرسلها الـWebhook واختر **Copy Message ID** (أو انسخ رابط الرسالة وخذ آخر رقم منه). الرقم **مو سر**.

## 2. أنشئ مستودع GitHub

1. أنشئ مستودعًا (Repository) جديدًا في GitHub من نوع **Public** لاستخدام GitHub Actions مجانًا مع جدول تحديث كل 5 دقائق. الكود علني لكن رابط الـWebhook يبقى سرًّا في GitHub Secrets. المستودع Private له حد دقائق مجانية وقد يترتب على تجاوزه رسوم حسب إعدادات الحساب.
2. ارفع الملف `update_status.py` والملف `.github/workflows/update.yml` **بنفس المسارات**. يمكن رفع المجلد كله باستخدام Git أو GitHub Desktop. تأكد أن فرع المستودع الافتراضي يحتوي الملفات.
3. افتح **Settings → Secrets and variables → Actions**.
4. تحت **Repository secrets** أضف السر:
   - Name: `DISCORD_WEBHOOK_URL`
   - Secret: الرابط الكامل الذي نسخته من ديسكورد.
5. تحت **Repository variables** أضف:
   - `DISCORD_MESSAGE_ID` = رقم الرسالة فقط.
   - `MC_SERVER_ADDRESS` = `CE5MF.aternos.me` (أو آيبي السيرفر الفعلي).
6. اذهب إلى **Actions → Update WLI Craft server status → Run workflow** لتجربة التحديث فورًا.
7. بعد نجاح أول تشغيل ستتحدث نفس الرسالة بشكل مجدول كل 5 دقائق تقريبًا (قد تتأخر بعض مرات التنفيذ).

## ملاحظات مهمة

- الحالة والعدد يتم جلبهما من https://api.mcsrvstat.us/3/؛ وهذه الخدمة تحتفظ بالبيانات في ذاكرة مؤقتة 5 دقائق.
- لما يكون السيرفر Offline لن يظهر رقم قديم للاعبين؛ تظهر عبارة «غير متاح».
- عند فشل الاتصال بالـAPI، يبقى آخر إيمبد بدل عرض نتيجة خاطئة.
- لا يمكن لبرنامج خارجي تعديل رسالة أرسلها بوت آخر عادة. يجب أن تكون رسالة Embed Generator مرسلة **بنفس Webhook الذي تملك رابطه**. إذا أرسلت الرسالة عبر **Channel**، أنشئ رسالة جديدة بوضع **Webhook**.
- إذا ظهر في GitHub Actions خطأ 404، تأكد أن رقم الرسالة صحيح وأن **الرسالة نفسها مرسلة من نفس الـWebhook**.
- إذا كشفت رابط الـWebhook بالخطأ، احذفه من ديسكورد وأنشئ واحدًا جديدًا.
- لو كان السيرفر Minecraft Bedrock بدل Java، يحتاج تعديل مسار الـAPI من `/3/` إلى `/bedrock/3/`.
- جدولة GitHub Actions قد تتأخر، وبعض سير العمل المجدولة تتعطل تلقائيًا عند خمول المستودع العام لفترة طويلة.
